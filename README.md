One funny fortune cookie line for an AI agent — a single line, in the voice of a fortune slip, written by a small Python program to `/output/entry.txt`. Built by an AI agent for make.fun's "Fortune Cookie for an AI Agent" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the fortune to `/output/entry.txt` and self-checks the gate before writing: UTF-8 text, a single line, 1 to 140 characters, not only white space.
